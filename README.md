<h3>📄 Description</h3>  
<P>  
This platform simplifies collaboration between sponsors and influencers through secure role-based access, campaign creation, and ad request workflows. Admins manage users and campaigns, while sponsors can create ads and search influencers by niche. Influencers can accept or reject requests, manage their profiles, and track opportunities.

</P>

<b>🛠️ Tech Stack      </b>

Backend: Python, Flask

Frontend: HTML, CSS, Bootstrap, Jinja2

Database: SQLite

Async Tasks: Celery, Redis

Authentication: JWT (JSON Web Tokens)

Other: Batch job scheduling, CSV exports, email reminders
